## Sobre o projeto

[O jogo se passa em um labirinto. O objetivo é coletar 20 pontos. O jogador deve esquivar os obstáculos.]

## O que o projeto faz

- [O jogador movimenta a bolinha usando as teclas WASD ou as setas.]
- [Ao encostar nos itens, eles desaparecem e o placar aumenta.]
- [Quando coleta todos os itens, aparece uma mensagem de vitória.]

## O que o projeto contém

- **Scripts:** [PlayerMov.cs: Controla o player e pontuação. CameraController.cs: Controla a camera. Rotator.cs: Roda os objetos.]
- **Objetos principais:** [Player, Ground, Walls, PickUp.]
- **Recursos usados:** [Rigidbody, Collider com Is Trigger, TextMeshPro etc.]

## Controles

- **WASD / Setas:** Movimentar o jogador.
